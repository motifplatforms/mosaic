## What each report contains (sign-in required)

| Page | What it shows |
|---|---|
| Overview | Average scores, score by rubric dimension, biggest gaps |
| Tasks | Every task with its brief and both models' scores |
| Compare | Both models side by side per task, with what drives each gap |
| Inputs | The files each task gave the agents, by kind, with links to public originals |
| Outputs | Every output file, what it is made of, check pass rates, value per dollar |
| Method | Pipeline, rubric, caps, design and limits |
| Sources | Provenance of the inputs and how faithfully each run cited them |
| Run viewer | Every page or slide as the judge saw it, with the judge's findings pinned to it |
